शांत टाइपिंग अभ्यास ऐप, जिसमें परिवेशीय ध्वनियाँ, व्यक्तिगत दैनिक अभ्यास और किसी खाते की आवश्यकता नहीं है।

## यह क्या है

लोकी टाइपर एक टाइपिंग अभ्यास ऐप है जो उन वयस्कों के लिए बनाया गया है जो बिना गेमिंग, लीडरबोर्ड या ध्यान भंग करने वाले तत्वों के शांत, केंद्रित सत्र चाहते हैं।

सभी डेटा आपके डिवाइस पर ही रहता है। कोई खाता नहीं। कोई क्लाउड नहीं। कोई ट्रैकिंग नहीं।

## अभ्यास मोड

- **फोकस** — लय और सटीकता बनाने के लिए शांत, क्यूरेटेड अभ्यास
- **वास्तविक जीवन** — ईमेल, फॉर्म, संदेश, नोट्स और अन्य दैनिक लेखन के साथ अभ्यास
- **प्रतिस्पर्धी** — व्यक्तिगत सर्वश्रेष्ठ के साथ समयबद्ध अभ्यास
- **दैनिक अभ्यास** — प्रत्येक दिन उत्पन्न अभ्यासों का एक नया सेट, जो आपके हालिया सत्रों के अनुसार अनुकूलित है
- **अध्ययन** — अपना स्वयं का पाठ जोड़ें। यह इस डिवाइस पर रहता है और एक समय में एक भाग के रूप में वापस आता है, क्रम में या फेरबदल करके।

## विशेषताएं

- निरंतर ध्यान के लिए डिज़ाइन की गई परिवेशीय ध्वनियाँ। सेटिंग्स में केवल उन श्रेणियों की सूची है जिनमें एक ट्रैक है।
- मैकेनिकल टाइपराइटर कीस्ट्रोक ऑडियो (वैकल्पिक), साथ ही क्लिकी, टिक और म्यूटेड। आपके द्वारा चुना गया कीबोर्ड उस रिकॉर्डिंग पर बना रहता है। डिफ़ॉल्ट रूप से मैकेनिकल।
- हालिया सत्रों के आधार पर व्यक्तिगत दैनिक अभ्यास
- पहली बार लोड होने के बाद पूर्ण ऑफ़लाइन समर्थन
- सुलभ: स्क्रीन रीडर मोड, कम गति, ध्वनि-वैकल्पिक

## विकास

### स्थानीय रूप से चलाएं

```bash
npm ci
npm run dev
```

### बनाएं

```bash
npm run build
npm run preview
```

### स्क्रिप्ट

- `npm run dev` — देव सर्वर
- `npm run build` — टाइपचेक + उत्पादन निर्माण
- `npm run verify` — सामग्री जांच, ध्वनि गेट, टाइपचेक, कवरेज और उत्पादन निर्माण
- `npm run typecheck` — केवल टाइपस्क्रिप्ट निर्माण टाइपचेक
- `npm run lint` — ईएसएलआईएनटी
- `npm run preview` — स्थानीय रूप से पूर्वावलोकन उत्पादन निर्माण
- `npm run validate:content` — सभी सामग्री पैकों के लिए स्कीमा + संरचनात्मक सत्यापन
- `npm run gen:phase2-content` — चरण 2 पैकों को पुन: उत्पन्न करें
- `npm run smoke:rotation` — नवीनता/रोटेशन स्मोक परीक्षण
- `npm run qa:ambient:assets` — परिवेशीय WAV संपत्ति जांच
- `npm run qa:sound-design` — ध्वनि डिजाइन स्वीकृति गेट
- `npm run qa:phase3:novelty` — दैनिक सेट नवीनता सिमुलेशन
- `npm run qa:phase3:recommendation` — अनुशंसा सैनिटी सिमुलेशन

### कोड संरचना

- `src/app` — ऐप वायरिंग (राउटर, शेल/लेआउट, वैश्विक प्रदाता)
- `src/features` — सुविधा-स्वामित्व वाली यूआई (पेज + सुविधा घटक)
- `src/lib` — साझा डोमेन तर्क (भंडारण, टाइपिंग मेट्रिक्स, ऑडियो/परिवेशीय, आदि)
- `src/content` — सामग्री प्रकार + सामग्री पैक लोडिंग

आर्किटेक्चर अनुबंधों और आयात सीमाओं के लिए `modular.md` देखें।

### आयात उपनाम

- `@app` → `src/app`
- `@features` → `src/features`
- `@content` → `src/content`
- `@lib` → `src/lib/public` (सार्वजनिक एपीआई सतह)
- `@lib-internal` → `src/lib` (ऐप वायरिंग/प्रदाताओं तक सीमित)

### मार्ग

- `/` — होम
- `/daily` — दैनिक अभ्यास
- `/focus` — फोकस मोड
- `/real-life` — वास्तविक जीवन मोड
- `/competitive` — प्रतिस्पर्धी मोड
- `/study` — अध्ययन, आपके द्वारा जोड़े गए पाठ के लिए
- `/focus/run/:exerciseId`, `/real-life/run/:exerciseId`, `/competitive/run/:exerciseId` — एक अभ्यास चलाएं
- `/practice` `/focus` पर रीडायरेक्ट करता है। `/arcade` `/competitive` पर रीडायरेक्ट करता है

सेटिंग्स हेडर से खुलती हैं। कोई अभ्यास-सूची पृष्ठ नहीं है।

### दस्तावेज़

- `modular.md` — आर्किटेक्चर + आयात सीमा अनुबंध
- `docs/sound-design.md` — परिवेशीय ध्वनि डिजाइन ढांचा
- `docs/sound-design-manifesto.md` — ध्वनि डिजाइन घोषणापत्र + स्वीकृति परीक्षण
- `docs/sound-philosophy.md` — सार्वजनिक-सामना करने वाला ध्वनि दर्शन
- `docs/accessibility-commitment.md` — पहुंच प्रतिबद्धता
- `docs/how-personalization-works.md` — वैयक्तिकरण स्पष्टीकरण

## सुरक्षा और डेटा दायरा

लोकी टाइपर एक टाइपिंग अभ्यास वेब ऐप (PWA + माइक्रोसॉफ्ट स्टोर) है जिसमें कोई खाता और कोई टेलीमेट्री नहीं है।

- **पहुंची गई डेटा:** ब्राउज़र लोकलस्टोरेज (प्राथमिकताएं, रन इतिहास, व्यक्तिगत सर्वश्रेष्ठ) और इंडेक्स्डडीबी डेटाबेस `lokey-study` (अध्ययन पृष्ठ पर आपके द्वारा जोड़ा गया पाठ)
- **पहुंची नहीं गई डेटा:** कोई क्लाउड सिंक नहीं। कोई टेलीमेट्री नहीं। कोई एनालिटिक्स नहीं। कोई खाता नहीं। कोई ट्रैकिंग नहीं
- **नेटवर्क:** ऐप अपने पृष्ठ और ऑडियो को उसी मूल से लोड करता है। यह किसी खाता सेवा, टेलीमेट्री एंडपॉइंट या किसी तृतीय-पक्ष एपीआई को कॉल नहीं करता है।
- **कोई टेलीमेट्री** एकत्र या भेजी नहीं जाती है
